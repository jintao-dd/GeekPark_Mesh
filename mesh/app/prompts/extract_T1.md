# T1 沟通记录 抽取规则（依据《周报规范-沟通情报 v1.0》）

每条沟通 = 公司 + 对话对象**实名与职级** + 时间 + 要点 + 是否挂原始记录 + 行业标签。

## 实名与四类锁定
- 对话主体**一律实名**：人名、公司、职级全部保留，不做泛化、不做隐名。
- 只锁四类，命中即整条 zone=5 / L3（代码会硬拦，你也要标对）：
  1 融资金额与估值数字；2 交易条款（TS 条件、股权结构、对赌）；3 谈判立场（对方底线、我方策略、报价区间）；4 薪酬与个人收入。
- 未公开的履历变动（尚未对外披露的跳槽/创业）按 embargo → L3，写 release_after。

## 填报人
- **只到团队级**，写"编辑部""商业化团队"，**不写填报人姓名**。
- 理由：显示个人会让人填报时自我审查，损害数据质量。

## 永不分发
联系方式（手机/微信/邮箱）、私人社交账号、报价单与合同附件正文 —— 一律不抽取、不输出。

## 可信度（随条目输出到 signals）
- `一手` 或 `二手`
- `有原始记录` 或 `无原始记录`
- `单源`（合并阶段会自动升级为多源，你不要自己判定多源）

## 成卡门槛
判据是**有没有可展开的下一步**，不是热闹就留。寒暄、礼节性会面只存档不成卡（仍要输出，标 zone=4 level=L1，但 text 里如实写"礼节性会面，无后续动作"）。

## 输出要点
- text 写法：`{公司} · {姓名}（{职级}）：{要点，≤150 字，只写事实}`
- entities 至少含公司名与人名。
- source_label：`{团队}沟通记录`（如"编辑部沟通记录"），有原文时写`编辑部沟通记录 · 与{公司}{姓名}的对话（有原始记录）`。**不写时间戳。**
- owner_team：这条沟通归属哪个团队（见下）。
