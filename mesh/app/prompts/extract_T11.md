# T11 视频号周数据 抽取规则（数据形态层；团队价值判断见 team_video）
形态：视频号后台导出的周表 CSV（已被系统转成"列名 | 值"文本），一行一条视频。常见列：标题 / 发布时间 / 播放 / 点赞 / 评论 / 转发 / 分享 / 完播率 / 平均观看时长 / 商业标记（或"合作""广告"字样）。列名可能略有不同，按语义对应。

## 步骤
1. 过滤：商业标记为是、或标题含明确广告/合作字样的行，不进入排序；整份输出一条 zone=2 说明"商业内容 N 条按规则不列"。
2. 只看发布时间落在"本期区间"内的行；区间外的只用作对照，不单独成条。
3. 排序：按 播放、点赞、评论、转发/分享、完播率 五项综合看，取本周表现最好的 3–5 条。综合判断由你做，不要只按播放量排；一条视频若播放不高但评论/完播率明显突出，也算表现好。
4. 每条选中的视频一条 zone=4 L1：text 写"《标题》：本周播放 N、点赞 N、评论 N（相对本周其余视频处于前列）"，数字照实写；entities 写视频里的公司/产品/人/话题词；roles 写"无"或"嘉宾"（若有出镜嘉宾）。
5. 额外输出一条 zone=4 kind=judgment：本周观众明显更关注的话题方向（一两句，标"数据判断"），供编辑部与播客对照。
- 不做评价：不写"表现差""拉胯"，不列末尾榜；未入选的视频不点名。
- source_label 只用：视频号周数据。发布日期放 pointer。
