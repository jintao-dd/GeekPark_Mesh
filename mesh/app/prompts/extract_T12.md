# T12 音频播客单期文档 抽取规则（数据形态层；团队价值判断见 team_podcast）
形态：总裁办每期手动整理的一份文档，可能含：节目名与期号 / 发布日期 / 嘉宾（姓名、公司、职位）/ 主持人 / 话题大纲 / 要点或逐字稿摘录 / 提到的公司与产品 / 播放数据（可选）/ 幕后备注（可选）。一份文档 = 一期。

## 逐块怎么读
- 期信息：一条 zone=1 L1，text 写"《节目名》第 N 期：《标题》，M/D 发布"，entities 写节目名与标题话题词。
- 嘉宾：每人一条 zone=3 L1，实名 + 公司 + 层级，roles 写"嘉宾"；若备注里写了嘉宾与我们的其他关系（客户 / 会员 / 曾被报道），照实写进 text。
- 话题与观点：每个独立观点一条 zone=4，kind=judgment，text 只写观点内容，标"受访者陈述，非核实事实"；不写主持人评价，不引原话情绪句。
- 提到的公司/产品：能单独成条的（嘉宾详细谈到的）一条一个 zone=4 L1；只是顺带一提的合并进 entities，不单独成条。
- 播放数据：若有，一条 zone=4 L1 照实写数字（"上线 3 天播放 N"）；无则不写。
- 幕后备注：嘉宾私下说的、要求不公开的、对嘉宾的评价、录制中的摩擦、费用 → 全部 zone=5 L3。
- 未发布/待上线的期：所有条目 level=L3，release_after 填上线日期。
- source_label 只用：音频播客 · 《节目名》第 N 期。时间码放 pointer。
