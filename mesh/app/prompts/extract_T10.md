# T10 Global Partnership 团队工作周报 抽取规则（数据形态层；团队价值判断见 team_gp）
形态：一份 DOCX 按周累积，每周一个"YYYYMMDD - YYYYMMDD GP 工作进展"标题，下分固定四栏：一、前沿社活跃度 & 粘性建设（日常活动 / 近场研究 / 年度活动 / 嘉宾名单）；二、商业营收进展 & 可能的商机（续费管理 / 商业化支持 & 商机）；三、战略资源建设（国际化合作伙伴 / 新发现的公司/嘉宾）；四、其他（Todo）。

## 只抽本期
- 用标题里的日期找到落在"本期区间"内的那一周（或几周），**只抽那部分**。更早的周不抽，唯一例外：同一件事在早先周里有记录、本周状态变了（未确认 → 已确认），可以在本周那条里带一句"上期状态：…"。
- 整份没有落在本期区间内的周 → 只输出一条 zone=2 说明"文档内无本期区间的周报"。
- 若输入里"本期区间"为"未指定"，取文档中日期最新的一周。

## 逐栏怎么读
- 嘉宾/参与名单（"姓名｜公司 职位"一行一人）：这是本栏最有价值的东西。每人一条 zone=3，L1，实名 + 公司 + 层级，roles 按身份写（前沿社会员→"社群成员"；外部嘉宾→"嘉宾"；机构代表→"资源"）；名单所属活动名写进 text。"代替会员参加""+1""待定"照实写，"可能放鸽子"这类批注剥离。
- 近场研究 / 拟联系的人：一条一人，写清"拟联系 / 已联系未回复 / 已确认"状态。若句子里提到别的团队也在联系同一人，照实写进 text 并把该团队写进 roles。
- 续费管理（谁付了、谁在催、谁说这周付）：**整段 zone=5，L3**，逐条输出但会被硬拦；不要遗漏，管理员要核对拦截。
- 商机（活动招募、报名人）：活动本身 zone=3 L1；报名人名单每人一条 zone=3 L1（这是客户阶段信息，允许实名 + "已报名/待定"）；**预计收入、报价、人均费用一律不写**。
- 国际化合作伙伴：一条一个机构，写清对方是谁、能提供什么（场地 / 高层联动 / 带企业家来华 / 联合活动）、当前状态。基金成立、募资中、基金规模 → 只写"新基金成立 / 在募资"，金额 zone=5。
- 新发现的公司/嘉宾：公司名 + 成立时间 + 做什么 + 创始人及履历 + 轮次与投资方名字（公开信息，L1）；金额不写；"X 月将融资宣发"这类 → 该条 level=L3，release_after 填宣发日期。
- Todo：每条 zone=2。涉及外部人的照实写（"隋国栋新加坡主体联动"）；"找老板探讨…"这类内部事务 zone=5；纯个人事务不抽。
- 冰岛/深圳等行程类：按"日程与计划"口径，cert 只能写 计划中 / 在谈 / 初步想法。

- source_label 只用：Global Partnership 工作周报提及。周标题日期放 pointer。
