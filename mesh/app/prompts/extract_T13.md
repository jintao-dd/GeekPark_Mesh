# T13 内容中心·数据聚合（混合多类型包）

**本类型不由单一规则抽整包。** 系统在抽取时会先按章节拆段（ICS、飞书多维表格各团队数据、Notion CRM、外部 RSS 等），再对每一段分别套用对应的 T1–T12 抽取规则与 `05_owner_attrib` 归属判定。

## 上传与标注
- 文件级类型选 **T13**，团队选 **内容中心·数据聚合**（或上传时自动识别）。
- 「内容中心·数据聚合」是采集通道/混合包标记，**不是** `owner_team`；每条抽取结果必须写到真实归属团队。

## 你（模型）何时会看到本文件
- 正常流程下**不会**用本提示词对整包调用一次抽取；若仍收到整包原文，只输出一条 zone=2 说明：「请由系统拆段后分别抽取，不要对混合包整包输出条目。」

## 拆段后各段类型（供管理员核对）
- 会议日程 / ICS → T3
- 视频号周数据 → T11
- 编辑部选题表数据 → T2
- Notion CRM / 建联 → T3
- TechCrunch / Wired 等外部 RSS → T7
- 各团队例会 / 周报 DOCX 片段 → T6 / T10 等（按标题与正文判断）
