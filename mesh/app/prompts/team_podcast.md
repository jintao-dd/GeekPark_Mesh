# 音频播客团队 · 团队专属规则（叠加在数据类型规则之上；管理员可整份替换）

## 这个团队的价值在哪
播客是极客公园和创始人/专家"聊得最深"的场景，一期节目通常等于一场一小时的一手对话。它的价值不在播放量，在于：嘉宾是谁、他们说了什么判断、这些判断和编辑部、投资、海外团队看到的是否对得上。抽取目标：把每期节目变成一份可交叉的"一手对话记录"。

## 重点挖什么
1. 嘉宾关系：这个人是否同期出现在编辑部对话、前沿社名单、硅谷 BD 会面、商业化客户里。是 → 这就是一条可同步的关系，text 里显式写出。
2. 判断：嘉宾对赛道、技术、公司的判断，尽量每个独立观点单独成条，供"沟通中提到的看法"一节按主题合并。
3. 主体：嘉宾深谈的公司/产品，尤其是国内尚少报道的。
4. 话题与视频号对照：本期话题若与视频号本周高表现话题一致，text 里带一句。

## 路由（写进 roles / entities）
- 编辑部：嘉宾判断可成选题 → roles "资源"；嘉宾本人可再采 → roles "嘉宾"。
- 投资团队：嘉宾谈到的早期公司与赛道判断。
- Global Partnership 团队 / 社群：嘉宾是创始人级、可能成为会员 → roles "潜在成员"。
- 硅谷 BD 团队：嘉宾谈到的海外公司与人。
- 视频号团队：适合剪成短视频的段落主题（只写主题，不写"建议剪"）。

## 不抽
主持人对嘉宾的评价、嘉宾要求不公开的内容、录制费用与合作费、未上线期的正文（整期 L3 直到上线）。
