# Global Partnership 团队 · 团队专属规则（叠加在数据类型规则之上；管理员可整份替换）

## 这个团队的价值在哪
GP 团队手里有两样别的团队没有的东西：一是前沿社——一群创始人级会员及其活动，二是国际机构与海外资本方的合作关系。它的周报数据形态不如硅谷 BD 丰富，但每一个名字的分量都很重。抽取目标：让全公司看见"这周哪些创始人和机构与我们有了接触、他们在做什么、谁能接上"。

## 重点挖什么
1. 人：每个出现的创始人/高管都值得单独成条，不要把名单压成"共 20 人参加"。挖：公司、层级、是否会员、本周与我们的接触形式（参加活动 / 拟拜访 / 报名行程 / 加入意向）、所在城市（新加坡、深圳、成都等地理信号对活动与采访排期都有用）。
2. 机构：Google、政府机构（DISG 类）、海外基金、孵化器。挖：对方能提供什么资源（场地、高层、资金方对接、带团来华）、合作节奏（季度联动、9 月带企业家来华），这些是总裁办和商业化最需要的。
3. 城市与场地信号："X 公司在新加坡有办公室可用""Y 在成都"——单独成条，zone=4，roles 写"资源"，entities 写城市名。
4. 新发现公司：创始人履历链（大疆→拓竹→影翎）是判断分量的关键，照实写。
5. 状态变化：谁从"拟联系"变成"已确认"，谁从"待定"变成"已报名"。

## 路由：每条必答"国内谁用得上"（写进 roles / entities）
- 编辑部：创始人级会员本身就是采访池；新发现公司是选题候选；"编辑部也在联系同一人"必须显式带上。
- 投资团队：新发现公司、海外基金动向（只写轮次与方向）。
- 商业化团队：Google 等大厂合作、有预算的机构。
- 硅谷 BD 团队：海外资本方计划带企业家来华、华人创始人回国——这是两个海外团队之间的接口，特别标出。
- 音频播客团队 / 视频号团队：能讲的创始人。
- 活动 / 总裁办：场地、城市、年度活动排期。

## ⑤区从严（这个团队的周报里⑤区内容密度很高）
续费/催款/付款状态、预计收入、人均费用、基金规模、LP 认购、"找老板聊"、对会员的评价、对合作方靠不靠谱的判断——全部 zone=5，一条不漏地标出来让系统拦，不要自作主张省略。
